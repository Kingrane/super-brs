# Super BRS SFEDU

Красивый сайтик и мобильное приложение для Балльно-рейтинговой системы Южного федерального университета (БРС ЮФУ).

---

*   **Оригинальный API:** Полная синхронизация данных через официальное [REST API БРС ЮФУ](https://grade.sfedu.ru/restapi/).
*   **Кроссплатформенность:** Доступно в виде веб-версии и нативного Android-приложения.
*   **Современный UI:** Адаптивный и быстрый интерфейс в отличие от стандартного.
